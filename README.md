# 🛡️ Operational System Auditor

**Operational System Auditor** adalah tools berbasis web (*client-side*) yang dirancang untuk mempermudah dan mempercepat proses validasi serta verifikasi data transaksi operasional secara otomatis.

---

## 🚀 Fitur Utama

- **Checker Deposit VS TO:** Membandingkan data transaksi *History Koin* (Deposit) dengan *Data Turnover (TO)* secara presisi.
- **Checker Manual Deposit:** Validasi manual untuk penginputan data deposit harian.
- **Pengecekan Deposit Balance:** Memastikan keseimbangan antara saldo masuk dan aktivitas akun.
- **Export Excel:** Mengunduh hasil olah data langsung ke dalam format tabel `.xlsx`.
- **Privasi Aman:** Semua pemrosesan data dilakukan di sisi browser pengguna tanpa mengirimkan data ke server eksternal.

---

## 💻 Cara Menggunakan Tools

1. Buka halaman aplikasi web secara langsung melalui link berikut:  
   👉 **[OPERATIONAL SYSTEM AUDITOR](https://auditorhose09-dev.github.io/OPERATIONAL_SYSTEM/)**
2. Pilih menu tools di bilah navigasi kiri (misal: **Checker Deposit VS TO**).
3. Salin (*copy*) teks log/data transaksi kamu, lalu tempelkan (*paste*) pada kolom yang tersedia.
4. Klik tombol **PROSES CHECK TO**.
5. Tinjau tabel hasil analisis yang muncul di layar, atau klik **DOWNLOAD EXCEL TO** untuk menyimpan laporan.

* **HTML5 & CSS3** (Custom Dark Theme & Responsive Layout)
